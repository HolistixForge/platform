# Examples

This directory contains optional examples and templates for the HolistixForge platform.

## Available Examples

### [devcontainer](./devcontainer/)

An optional development container configuration using VS Code Server (code-server). This provides a containerized development environment that can be used with VS Code Desktop's Remote Containers extension or accessed directly through a web browser.

**Usage**: This is completely optional. If you want to use it, copy or symlink the `devcontainer` directory to `.devcontainer` in the repository root.

## Purpose

These examples are provided as references and starting points. They are not required for development and can be customized or ignored based on your team's preferences and workflow.
